# 🌐 YouTube Learning Platform Web

The web-based dashboard for the structured learning platform, providing a responsive interface for managing and following learning paths.

## ✨ Features

- **Responsive Dashboard**: View your enrolled paths and progress on any device.
- **Course Discovery**: Browse and search through the platform's course catalog.
- **Structured Learning**: Follow paths that organize individual courses into logical sequences.

## 🛠️ Technology Stack

- **Framework**: [React](https://reactjs.org/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: Vanilla CSS with modern flexbox and grid layouts
- **HTTP Client**: Fetch API

## 🚀 Getting Started

### Installation

1. Navigate to the frontend directory:
   ```bash
   cd frontend
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:5173](http://localhost:5173) in your browser.

## 📁 Project Structure

- `src/components`: UI building blocks
- `src/pages`: Main application views
- `src/App.jsx`: Application entry and routing
- `src/index.css`: Global styles and design system tokens
